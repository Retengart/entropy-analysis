# Поэтические признаки для распознавания авторов

## Что добавлено

**12 универсальных признаков** для анализа ЛЮБОЙ русской поэзии (не только Пушкин/Лермонтов):

### Структурные
- `meter_pattern` — размер стиха (по слогам в строке)
- `meter_regularity` — стабильность ритма
- `rhyme_scheme` — схема рифмовки (ABAB/AABB/ABBA/вольная)
- `rhyme_quality` — разнообразие рифм

### Синтаксические
- `enjambment_rate` — переносы фраз между строками
- `exclamation_ratio` — эмоциональность (восклицания)
- `question_ratio` — философичность (вопросы)

### Лексические
- `adjective_density` — плотность прилагательных
- **Автоматические лексиконы** — для каждого автора извлекаются характерные слова через TF-IDF

### Фонетические
- `consonant_repetition` — аллитерация
- `voiced_consonant_ratio` — звонкость согласных

---

## Автоматические лексиконы

**Не нужно хардкодить слова!** Система автоматически найдёт характерные слова для ЛЮБОГО автора:

```python
# Пример использования
from src.entropy_analysis.core.recognition_batch import train_and_run_batch, Segment

segments = [
    Segment("текст стихов автора 1", label="автор1"),
    Segment("текст стихов автора 2", label="автор2"),
    # ... любые авторы
]

result = train_and_run_batch(
    segments,
    feature_profile="poetry_essential",  # или poetry_full
    use_author_lexicons=True  # автоматически извлечёт слова через TF-IDF
)

# Система сама создаст признаки: lexicon_автор1, lexicon_автор2, ...
```

---

## Профили

| Профиль | Признаков | Для чего |
|---------|-----------|----------|
| `poetry_essential` | ~7-10 | Оптимально для стихов |
| `poetry_full` | ~10-15 | Максимум признаков |

При `use_author_lexicons=True` для каждого автора добавляется ещё +1 признак автоматически.
