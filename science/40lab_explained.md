# Алгоритм распознавания (практическая 40) — понятное объяснение

## Что решает
Классифицирует объект по заранее заданным классам `A1..AM`, используя дискретные признаки `x_k` (каждый имеет несколько возможных значений). Строит:
- информативность каждого признака (по Шеннону);
- вероятность ошибки распознавания по одному признаку;
- вероятность ошибки по комбинациям признаков (пары, расширяемо);
- чувствительность к помехам (разница ошибок без/с шумом).

## Входные данные
- `M` — число классов. Приоритеты классов: `P(A_i)` (сумма = 1).
- `N` — число признаков. Для каждого признака `k`:
  - `R_k` — число значений.
  - Матрица условных вероятностей `P(x^k_l | A_i)`, размер `(M, R_k)`, строки нормированы.
- Порог допустимой ошибки `P(e)_zad` (например, 0.05).
- (Опционально) шум: величина `factor` (± добавка), `seed` для детерминизма, режим нормализации.

## Основные расчёты (без помех)
1) **Маргинал по значению признака**  
   `P(x_l^k) = Σ_i P(A_i) * P(x_l^k | A_i)`

2) **Информативность признака** (формула (3) в лабе)  
   `H_k = -Σ_i P(A_i) log2 P(A_i) + Σ_l P(x_l^k) Σ_i P(A_i|x_l^k) log2 P(A_i|x_l^k)`  
   где `P(A_i|x_l^k) = P(A_i) P(x_l^k|A_i) / P(x_l^k)`.

3) **Ошибка по одному признаку** (формула (4))  
   `P(e)_k = Σ_l { P(x_l^k) - max_i [ P(A_i) P(x_l^k|A_i) ] }`  
   Берём класс с максимумом апостериорной вероятности, всё остальное — ошибка.

4) **Сравнение с порогом**  
   Если `P(e)_k < P(e)_zad`, признак проходит критерий.

5) **Ошибка по двум признакам** (формулы (5–8))  
   Для всех комбинаций значений `(x^k_l, x^q_m)` считаем  
   `P(b_j|A_i) = P(x^k_l|A_i) * P(x^q_m|A_i)`  
   `P(b_j) = Σ_i P(A_i) P(b_j|A_i)`  
   `P(e)_{k,q} = Σ_j { P(b_j) - max_i [ P(A_i) P(b_j|A_i) ] }`  
   Выбираем пару с минимальной ошибкой; сравниваем с `P(e)_zad`.

6) **Лучший признак / лучшая пара**  
   - Лучший одиночный — с минимальным `P(e)_k` (для отчёта сортируем по информативности).  
   - Лучшая пара — с минимальным `P(e)_{k,q}`.

## Учёт помех
1) Добавляем шум `±factor` к каждой ячейке `P(x^k_l | A_i)`, обрезаем ниже 0.  
2) Ренормируем строки (или fallback к равномерному, если сумма почти 0).  
3) Повторяем расчёты 1–6.  
4) Эффект помех:  
   - `ΔP = P^*(e)_min - P(e)_min` (абсолютная разница)  
   - `δP = ΔP / P^*(e)_min` (относительная, формула (1)).

## Сложность
- Одиночный признак: `O(M * R_k)` для ошибки и информативности.
- Пара признаков: `O(M * R_k * R_q)` (перебор всех комбинаций значений).

## Проверки и защита от ошибок
- Нормировка `P(A_i)` и каждой строки `P(x^k_l | A_i)`.
- Запрет отрицательных/NaN/∞, обязательное наличие хотя бы одного признака.
- Клиппинг и `EPS` для логов, детерминированный шум по `seed`.

## Как пользоваться в проекте
- **API**: `POST /api/v1/recognition` (см. пример в `README.md`).  
- **Streamlit**: вкладка `🧭 Распознавание` — ввод JSON, просмотр информативности, ошибок и влияния шума.  
- **Пример**: встроенный preset соответствует описанному в `science/40lab.md` (M=3, N=2, R=[2,3]).

## Интерпретация результатов
- **Информативность**: чем выше, тем признак лучше разделяет классы (Шеннон).  
- **P(e)**: ожидаемая вероятность ошибочного отнесения.  
- **Лучший признак/пара**: минимизируют P(e); при проектировании системы начинайте с них.  
- **ΔP, δP**: чувствительность алгоритма к помехам; большие значения = уязвимость, стоит усилить устойчивость или измерения.
