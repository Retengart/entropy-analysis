# Release Notes - Версия 2.0

## 🎉 Основные новшества

### ✅ Реализовано

#### 1. Полная система фильтрации (4 параметра)

**Параметры CLI:**
- `--min-entropy <ЧИСЛО>` - минимальная энтропия H
- `--max-entropy <ЧИСЛО>` - максимальная энтропия H  
- `--min-n-words <ЧИСЛО>` - минимальное количество слов N
- `--max-n-words <ЧИСЛО>` - максимальное количество слов N

**Применение:**
- Исключение выбросов
- Фокусировка на конкретном диапазоне
- Улучшение визуализации графиков
- Более точный расчет корреляции

#### 2. Автоматическое подписывание точек

**Параметр CLI:**
- `--label-top-entropy <N>` - подписать N текстов с максимальной энтропией

**Визуальные особенности:**
- Подписанные точки выделены **красным** цветом
- Имя файла отображается рядом с точкой
- Размер точки увеличен для видимости

**Применение:**
- Быстрое обнаружение аномальных текстов
- Валидация данных
- Научный анализ

#### 3. Улучшенные легенды

**Что изменилось:**
- Легенды показывают количество точек: `n = 450`
- Для двух авторов: `Пушкин (n=250)`, `Лермонтов (n=200)`

#### 4. Информативный консольный вывод

**При использовании фильтров:**
```
Filters applied: min_entropy=Some(2.5), max_entropy=Some(4.5), 
                 min_n_words=Some(50), max_n_words=Some(1000)
Labeling top 3 texts by entropy
Samples: 156
```

## ⚠️ Важные замечания

### Поведение фильтров
1. Фильтры применяются **только** к графикам и расчету корреляции
2. CSV и JSON файлы содержат **все** данные без фильтрации
3. После фильтрации должно остаться минимум 2 точки для корреляции

### Рекомендации по использованию
1. Начинайте с анализа без фильтров
2. Изучите распределение данных
3. Примените фильтры для исключения выбросов
4. Используйте `--label-top-entropy` для выявления интересных текстов

## 🐛 Известные ограничения

1. **Количество подписей** - слишком много подписей (>10) могут перекрываться
2. **Длинные имена файлов** - очень длинные имена могут выходить за границы графика
3. **Малые выборки** - фильтрация может оставить мало точек для корреляции

### Обходные решения:
1. Используйте `--label-top-entropy` с разумным числом (3-5)
2. Переименуйте файлы на короткие имена
3. Проверяйте количество отфильтрованных точек в консольном выводе
