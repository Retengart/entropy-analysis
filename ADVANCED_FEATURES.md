## 📊 1. Расширенная статистика

### Что включено

При использовании флага `--show-extended-stats` программа вычисляет и отображает полный набор статистических метрик для распределения энтропии:

- **Median** - медиана (50-й процентиль)
- **Q1** - первый квартиль (25-й процентиль)
- **Q3** - третий квартиль (75-й процентиль)
- **IQR** - интерквартильный размах (Q3 - Q1)
- **Variance** - дисперсия
- **Std Dev** - стандартное отклонение
- **CV** - коэффициент вариации (%)
- **Skewness** - асимметрия распределения
- **Kurtosis** - эксцесс (островершинность)

### Примеры использования

```bash
# Показать расширенную статистику для корпуса
cargo run --release -- batch poems/ \
    --show-extended-stats \
    --correlation
```

### Пример вывода

```
=== Extended Statistics (Entropy H) ===
Median:      3.856234
Q1 (25%):    3.654321
Q3 (75%):    4.023456
IQR:         0.369135
Std Dev:     0.234567
Variance:    0.055021
CV (%):      6.12
Skewness:    -0.145678
Kurtosis:    0.234567
```

### Интерпретация метрик

#### Медиана (Median)
- Центральное значение распределения
- Более робастна к выбросам, чем среднее
- Полезна для оценки "типичной" энтропии

#### Интерквартильный размах (IQR)
- Содержит центральные 50% данных
- Используется для определения выбросов
- Меньший IQR → более однородный стиль

#### Коэффициент вариации (CV)
- Нормализованная мера разброса
- CV < 15% → низкая вариативность
- CV > 30% → высокая вариативность
- Позволяет сравнивать разные корпуса

#### Асимметрия (Skewness)
- Skewness > 0 → больше текстов с низкой энтропией
- Skewness < 0 → больше текстов с высокой энтропией
- |Skewness| < 0.5 → распределение близко к симметричному

#### Эксцесс (Kurtosis)
- Kurtosis > 0 → более "острое" распределение с тяжелыми хвостами
- Kurtosis < 0 → более "плоское" распределение
- |Kurtosis| < 1 → близко к нормальному распределению

## 🔍 2. Автоматическое определение выбросов

### Три метода определения

#### 1. IQR (Interquartile Range) - Рекомендуемый метод
```bash
cargo run --release -- batch poems/ \
    --auto-filter-outliers iqr \
    --outlier-threshold 1.5
```

**Как работает:**
- Вычисляет Q1 и Q3
- Выбросы: значения < Q1 - k×IQR или > Q3 + k×IQR
- Порог по умолчанию: k = 1.5
- k = 1.5 → "мягкое" определение
- k = 3.0 → "строгое" определение

**Когда использовать:**
- Универсальный метод
- Робастен к асимметричным распределениям
- Не требует нормальности данных

#### 2. Z-Score - Классический метод
```bash
cargo run --release -- batch poems/ \
    --auto-filter-outliers z-score \
    --outlier-threshold 3.0
```

**Как работает:**
- Z-score = (значение - среднее) / стд. отклонение
- Выбросы: |Z-score| > порог
- Порог по умолчанию: 3.0 (99.7% данных)

**Когда использовать:**
- Данные близки к нормальному распределению
- Нужна стандартная метрика
- Для сравнения с литературой

#### 3. Modified Z-Score - Робастный метод
```bash
cargo run --release -- batch poems/ \
    --auto-filter-outliers modified-z-score \
    --outlier-threshold 3.5
```

**Как работает:**
- Использует медиану вместо среднего
- Modified Z = 0.6745 × (значение - медиана) / MAD
- MAD = Median Absolute Deviation
- Порог по умолчанию: 3.5

**Когда использовать:**
- Данные имеют много выбросов
- Распределение сильно асимметрично
- Нужна максимальная робастность

### Визуализация выбросов

Выбросы отмечаются на графике **пурпурным цветом** (MAGENTA):

```bash
cargo run --release -- batch poems/ \
    --correlation-plot outliers.svg \
    --mark-outliers iqr
```

### Автоматическая фильтрация


## ⚖️ 3. Нормализация энтропии

### Проблема

Энтропия H зависит от длины текста N:
- Короткие тексты → низкая энтропия (не все буквы встречаются)
- Длинные тексты → высокая энтропия (насыщение алфавита)
- Невозможно напрямую сравнивать тексты разной длины

### Решение 1: Нормализованная энтропия

```bash
cargo run --release -- batch poems/ \
    --normalized-entropy \
    --correlation-plot normalized.svg
```

**Формула:** `H_norm = H / log₂(N)`

**Свойства:**
- 0 ≤ H_norm ≤ 1
- H_norm = 1 → идеально равномерное распределение
- H_norm = 0 → все слова начинаются с одной буквы
- Не зависит от длины текста

**Когда использовать:**
- Сравнение текстов разной длины
- Оценка относительного разнообразия
- Нормализация для ML моделей

### Решение 2: Энтропийная скорость

```bash
cargo run --release -- batch poems/ \
    --entropy-rate \
    --correlation-plot rate.svg
```

**Формула:** `h = H / N`

**Свойства:**
- Показывает "энтропию на слово"
- Полезна для теоретических оценок
- Связана с информационной теорией

**Когда использовать:**
- Теоретический анализ
- Сравнение с моделями языка
- Оценка информационной плотности

### Комбинированное использование

```bash
cargo run --release -- batch poems/ \
    --normalized-entropy \
    --entropy-rate \
    --show-extended-stats \
    --correlation-plot full_analysis.svg
```

## 📖 Технические детали

### Вычисление квартилей

Используется линейная интерполяция:
```
Q(p) = x[i] × (1 - w) + x[i+1] × w
где i = floor(p × (n - 1)), w = p × (n - 1) - i
```

### Вычисление асимметрии

Используется коэффициент Фишера-Пирсона:
```
Skewness = E[(X - μ)³] / σ³
```

### Вычисление эксцесса

Используется избыточный эксцесс (excess kurtosis):
```
Kurtosis = E[(X - μ)⁴] / σ⁴ - 3
```

Нормальное распределение имеет Kurtosis = 0.

### MAD (Median Absolute Deviation)

```
MAD = median(|X - median(X)|)
```

Робастная альтернатива стандартному отклонению.

## 🎓 Интерпретация результатов

### Здоровый корпус

```
CV (%): 5-10%

Kurtosis: -1 до 1

```

### Проблемный корпус

```
CV (%): > 20%
|Skewness| > 1
|Kurtosis| > 2
Outliers: > 10% текстов
```

**Возможные причины:**
- Смешение жанров
- Технические тексты в корпусе
- Ошибки обработки
- Несколько авторов

## 🚀 Производительность

Все новые функции оптимизированы:
- Вычисление статистики: O(n log n) из-за сортировки
- Определение выбросов: O(n)
- Нормализация: O(1) для каждого текста

Для корпуса из 1000 текстов:
- Расширенная статистика: ~1 мс
- Определение выбросов: ~2 мс
- Нормализация: ~0.1 мс на текст

## ⚠️ Важные замечания

1. **Расширенная статистика** вычисляется для всего корпуса, не для отдельных текстов
2. **Автоматическая фильтрация** применяется только к анализу, CSV/JSON содержат все данные
3. **Нормализованная энтропия** может быть > 1 для очень коротких текстов (N < алфавит)
4. **Определение выбросов** требует минимум 3 текста в корпусе
