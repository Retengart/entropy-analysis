# Changelog - Фильтрация данных и улучшенные легенды

## Версия: 2024-09-29

### ✨ Новые возможности

#### 1. Параметры фильтрации через CLI
Добавлены два новых параметра командной строки для команд `batch` и `multi-poem`:

- `--min-entropy <ЧИСЛО>` - минимальное значение энтропии H (в битах)
  - Исключает точки с энтропией ниже указанного значения
  - Пример: `--min-entropy 2.5`

- `--max-n-words <ЧИСЛО>` - максимальное количество слов N
  - Исключает точки с количеством слов выше указанного значения
  - Пример: `--max-n-words 800`

#### 2. Информативные легенды на графиках
Легенды теперь показывают количество отображаемых точек:

**До:**
```
Correlation: H vs N (r = 0.3234, R² = 0.1046)
```

**После:**
```
Correlation: H vs N (r = 0.3234, R² = 0.1046), n = 450
```

Для двухавторских графиков:
```
Пушкин (n=250)
Лермонтов (n=200)
```

#### 3. Информация о фильтрах в консольном выводе
При использовании фильтров программа выводит:
```
Filters applied: min_entropy=Some(2.5), max_n_words=Some(800)
Samples: 180
Correlation coefficient (r): 0.456789
```

### 📝 Примеры использования

#### Пример 1: Исключить выбросы с низкой энтропией
```bash
cargo run --release -- batch test_poems/ \
    --correlation-plot filtered.svg \
    --min-entropy 2.5
```

#### Пример 2: Сосредоточиться на коротких текстах
```bash
cargo run --release -- batch test_poems/ \
    --correlation-plot filtered.svg \
    --max-n-words 800
```

#### Пример 3: Комбинированная фильтрация
```bash
cargo run --release -- batch test_poems/ \
    --correlation \
    --correlation-plot filtered.svg \
    --min-entropy 2.5 \
    --max-n-words 8000
```

### 🎯 Практическое применение

**Проблема:** На графике появляются точки, расположенные очень далеко от других, что искажает визуализацию и результаты корреляции.

**Решение:** Используйте новые параметры фильтрации для:
- Исключения текстов с аномально низкой энтропией
- Ограничения анализа текстами определенной длины
- Фокусировки на интересующем диапазоне значений

**Важно:** Фильтры применяются только к графикам и расчету корреляции. CSV и JSON файлы содержат все данные без фильтрации.
