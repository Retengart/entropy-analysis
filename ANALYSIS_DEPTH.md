# Анализ глубины сравнения авторов

## Текущая реализация

### Что используется сейчас:

1. **Основная метрика энтропии (Shannon Entropy)**:
   - Использует только **первые буквы слов** (`count_first_letters`)
   - Это **униграммы букв** - анализируется только распределение первых букв
   - Не учитывается контекст и последовательности букв

2. **Биграммы и триграммы**:
   - Считаются на **словах (токенах)**, а не на буквах
   - `bigram_entropy` и `trigram_entropy` используют `calculate_ngram_entropy(tokens, n=2/3)`
   - Это n-граммы **слов**, а не букв
   - **НЕ используются** в статистических тестах при сравнении авторов

3. **Статистические тесты при сравнении авторов**:
   - Энтропия H (первые буквы слов)
   - Perplexity (на основе энтропии первых букв)
   - Evenness (равномерность распределения первых букв)

### Проблемы текущего подхода:

1. **Поверхностный анализ**: Используются только первые буквы слов, игнорируется:
   - Последовательности букв внутри слов
   - Контекстные зависимости между буквами
   - Структурные паттерны текста

2. **Отсутствие биграмм/полиграмм букв**: 
   - Биграммы и триграммы считаются только на словах
   - Нет анализа последовательностей букв (например, "ст", "ов", "ен" и т.д.)
   - Это критично для русского языка, где сочетания букв несут важную информацию

3. **Ограниченная информативность**:
   - Распределение первых букв может быть похожим у разных авторов
   - Не учитываются стилистические особенности использования буквенных сочетаний
   - Упускаются морфологические и фонетические паттерны

## Рекомендации для улучшения

### 1. Добавить биграммы и триграммы букв

**Что нужно сделать:**
- Создать функцию для извлечения всех букв из текста (не только первых)
- Рассчитать энтропию биграмм и триграмм **букв**
- Использовать эти метрики в статистических тестах

**Пример реализации:**
```python
def extract_all_letters(self, text: str) -> Iterator[str]:
    """Извлекает все буквы из текста (не только первые)."""
    for match in WORD_PATTERN.finditer(text):
        token = match.group()
        for char in token:
            normalized = self.normalize_char(char)
            if normalized is not None:
                yield normalized

def calculate_letter_bigram_entropy(text: str) -> float:
    """Энтропия биграмм букв."""
    letters = list(self.normalizer.extract_all_letters(text))
    return calculate_ngram_entropy(letters, n=2)

def calculate_letter_trigram_entropy(text: str) -> float:
    """Энтропия триграмм букв."""
    letters = list(self.normalizer.extract_all_letters(text))
    return calculate_ngram_entropy(letters, n=3)
```

### 2. Использовать контекстные метрики

**Что добавить:**
- Условная энтропия букв (H(буква | предыдущая буква))
- Марковские цепи для моделирования последовательностей букв
- Анализ переходных вероятностей между буквами

### 3. Расширить статистические тесты

**Что включить в сравнение:**
- Энтропия биграмм букв
- Энтропия триграмм букв
- Условная энтропия букв
- Распределение частот биграмм/триграмм (KL divergence, JS divergence)

### 4. Анализ на разных уровнях

**Многоуровневый подход:**
1. **Уровень букв**: униграммы, биграммы, триграммы букв
2. **Уровень первых букв**: текущий подход (сохранить для совместимости)
3. **Уровень слов**: биграммы и триграммы слов (уже есть, но не используются в сравнении)
4. **Уровень фраз**: анализ структуры предложений
