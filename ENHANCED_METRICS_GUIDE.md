# 🔬 Руководство по улучшенным метрикам

## Обзор

Помимо стандартных метрик (энтропия Шеннона, индекс Симпсона, закон Ципфа), система теперь включает **10 дополнительных метрик** для более глубокого и точного анализа текстов.

Эти метрики обеспечивают:
- ✅ **Лучшую интерпретируемость** - понятные для человека значения
- ✅ **Многогранный анализ** - разные аспекты распределения
- ✅ **Научную строгость** - проверенные статистические методы
- ✅ **Практическую применимость** - для реальных задач анализа текстов

---

## 📊 Категории метрик

### 1. Интерпретируемость

#### Perplexity (Перплексия)
**Формула:** `PP = 2^H`

**Значение:** Эффективное число категорий - сколько равновероятных букв дало бы ту же энтропию.

**Интерпретация:**
- PP = 5 → текст использует буквы так, как если бы было 5 равновероятных букв
- PP = 20 → высокое разнообразие, эквивалентно 20 равновероятным буквам
- PP = 2 → низкое разнообразие, почти двоичное распределение

**Применение:** Интуитивная мера разнообразия, легче интерпретируется чем энтропия.

```python
result = analyzer.analyze(text)
print(f"Perplexity: {result.enhanced.perplexity:.2f}")
# Output: Perplexity: 13.59 (эквивалентно ~14 буквам)
```

---

### 2. Использование алфавита

#### Alphabet Utilization (Использование алфавита)
**Формула:** `U = n_unique / alphabet_size`

**Значение:** Какая доля букв алфавита реально используется в тексте.

**Интерпретация:**
- U > 0.8 (80%) → отлично, используется большая часть алфавита
- 0.6 < U ≤ 0.8 → хорошо, используется большинство букв
- U ≤ 0.6 → ограниченное использование алфавита

**Применение:** Оценка лексического богатства, детектирование специфичных текстов.

#### Uniqueness Ratio (Коэффициент уникальности)
**Формула:** `UR = n_unique_letters / n_words`

**Значение:** Сколько уникальных букв приходится на одно слово.

**Интерпретация:**
- UR > 0.5 → высокое разнообразие начальных букв
- 0.3 < UR ≤ 0.5 → умеренное разнообразие
- UR ≤ 0.3 → низкое разнообразие (повторяющиеся начальные буквы)

---

### 3. Концентрация и разнообразие

#### Herfindahl-Hirschman Index (Индекс Херфиндаля)
**Формула:** `HHI = Σ(p_i^2)`

**Значение:** Мера концентрации распределения.

**Диапазон:** [1/n, 1], где n - количество категорий

**Интерпретация:**
- HHI → 1 → высокая концентрация (доминирует одна буква)
- HHI → 1/n → низкая концентрация (равномерное распределение)
- HHI = 0.1 для 28 букв → умеренная концентрация

**Применение:** Экономический индекс, адаптированный для лингвистики. Показывает "монополию" отдельных букв.

```python
# Пример: сравнение концентрации
text1 = "Мама мыла раму"  # Высокая концентрация 'м'
text2 = "В лесу родилась ёлочка"  # Более равномерное

r1 = analyzer.analyze(text1)
r2 = analyzer.analyze(text2)

print(f"HHI текст1: {r1.enhanced.herfindahl_index:.4f}")  # Выше
print(f"HHI текст2: {r2.enhanced.herfindahl_index:.4f}")  # Ниже
```

#### Evenness / Pielou's J (Равномерность)
**Формула:** `J = H / log₂(S)`, где S - число используемых букв

**Значение:** Насколько равномерно распределены частоты между используемыми буквами.

**Диапазон:** [0, 1]

**Интерпретация:**
- J = 1.0 → идеально равномерное распределение
- J > 0.9 → очень равномерное
- 0.7 < J ≤ 0.9 → умеренно равномерное
- J ≤ 0.7 → неравномерное (доминируют отдельные буквы)

**Применение:** Экологический индекс, используется для оценки биоразнообразия. В лингвистике - оценка сбалансированности использования букв.

---

### 4. Отклонение от идеала

#### Uniformity Distance (Расстояние от равномерности)
**Формула:** `d = ||p - u||₂ = √(Σ(p_i - 1/n)²)`

**Значение:** Евклидово расстояние фактического распределения от идеального равномерного.

**Интерпретация:**
- d = 0 → идеально равномерное распределение
- d → 1 → максимально неравномерное
- d < 0.3 → близко к равномерному
- d > 0.5 → сильное отклонение

**Применение:** Геометрическая мера отклонения. Полезна для сравнения с "нулевой гипотезой" равномерности.

#### Redundancy (Избыточность)
**Формула:** `R = 1 - H/H_max`

**Значение:** Доля неиспользованной информационной ёмкости.

**Диапазон:** [0, 1]

**Интерпретация:**
- R = 0 → нет избыточности, максимальная энтропия
- R = 0.5 → используется 50% информационной ёмкости
- R = 1 → полная избыточность, только одна буква

**Применение:** Теория информации. Показывает, насколько текст "сжимаем" с точки зрения распределения букв.

```python
# Пример: сравнение избыточности
result = analyzer.analyze(text)
e = result.enhanced

print(f"Redundancy: {e.redundancy*100:.1f}%")
print(f"Используется {100-e.redundancy*100:.1f}% информационной ёмкости")
# Output: Redundancy: 22.5%
#         Используется 77.5% информационной ёмкости
```

### 5. Семейство энтропий Реньи

**Общая формула:** `H_α = (1/(1-α)) × log₂(Σp_i^α)`

Энтропия Реньи обобщает понятие энтропии через параметр порядка α. Разные значения α дают разную чувствительность к редким vs частым событиям.

#### H₀ - Hartley Entropy (Энтропия Хартли)
**При:** α → 0

**Формула:** `H₀ = log₂(S)`, где S - число используемых букв

**Значение:** Зависит только от количества используемых букв, не от частот.

**Применение:** Базовая мера разнообразия. Полезна, когда важно только наличие/отсутствие, а не частоты.

#### H₁ - Shannon Entropy (Энтропия Шеннона)
**При:** α = 1 (предел)

**Формула:** `H₁ = -Σ(p_i × log₂(p_i))`

**Значение:** Стандартная информационная энтропия.

**Применение:** Оптимальный баланс между редкими и частыми буквами. Наиболее используемая мера.

#### H₂ - Collision Entropy (Энтропия столкновений)
**При:** α = 2

**Формула:** `H₂ = -log₂(Σp_i²)`

**Значение:** Связана с вероятностью того, что две случайно выбранные буквы совпадут.

**Применение:** Более чувствительна к частым буквам. Используется в криптографии, теории кодирования.

#### H∞ - Min-entropy (Минимальная энтропия)
**При:** α → ∞

**Формула:** `H∞ = -log₂(max(p_i))`

**Значение:** Определяется только самой частой буквой.

**Применение:** Энтропия "наихудшего случая". Критична для криптографических применений.

---

### Спектр Реньи и монотонность

**Важное свойство:** H₀ ≥ H₁ ≥ H₂ ≥ H∞

Это всегда выполняется для любого распределения вероятностей.

**Интерпретация спектра:**
- Узкий спектр (значения близки) → распределение близко к равномерному
- Широкий спектр (большая разница) → есть доминирующие элементы

```python
# Пример: анализ спектра Реньи
result = analyzer.analyze(text)
e = result.enhanced

print("Спектр энтропий Реньи:")
print(f"H₀ (Hartley):    {e.renyi_0:.4f}")
print(f"H₁ (Shannon):    {result.shannon_entropy:.4f}")
print(f"H₂ (Collision):  {e.renyi_2:.4f}")
print(f"H∞ (Min):        {e.renyi_inf:.4f}")
print(f"\nШирина спектра: {e.renyi_0 - e.renyi_inf:.4f}")

# Output:
# Спектр энтропий Реньи:
# H₀ (Hartley):    4.0000
# H₁ (Shannon):    3.7649
# H₂ (Collision):  3.5353
# H∞ (Min):        2.5146
#
# Ширина спектра: 1.4854
```

## 🎯 Практическое применение

### 1. Атрибуция авторства

Разные авторы имеют разные "отпечатки" в метриках:

```python
# Сравнение авторов
authors = {
    "Пушкин": pushkin_text,
    "Достоевский": dostoevsky_text,
}

for name, text in authors.items():
    r = analyzer.analyze(text, source_name=name)
    e = r.enhanced
    print(f"{name}:")
    print(f"  Perplexity: {e.perplexity:.2f}")
    print(f"  Evenness: {e.evenness:.3f}")
    print(f"  HHI: {e.herfindahl_index:.4f}")
```

### 2. Оценка сложности текста

Комбинация метрик дает оценку сложности:

```python
def estimate_complexity(result):
    e = result.enhanced
    
    # Взвешенная сумма метрик
    score = (
        result.shannon_entropy * 0.3 +
        e.perplexity * 0.2 +
        e.alphabet_utilization * 5 +
        e.evenness * 3
    )
    
    if score < 5:
        return "Простой"
    elif score < 8:
        return "Средний"
    else:
        return "Сложный"
```

### 3. Детектирование аномалий

Необычные значения метрик могут указывать на:
- Технические тексты (низкое использование алфавита)
- Повторяющийся текст (высокий HHI)
- Списки/перечисления (низкая evenness)

```python
def detect_anomalies(result):
    e = result.enhanced
    anomalies = []
    
    if e.alphabet_utilization < 0.3:
        anomalies.append("Очень ограниченный алфавит")
    
    if e.herfindahl_index > 0.2:
        anomalies.append("Высокая концентрация букв")
    
    if e.evenness < 0.6:
        anomalies.append("Сильная неравномерность")
    
    return anomalies
```

## 🔧 Использование в коде

### Базовое использование

```python
from entropy_analysis import TextAnalyzer

analyzer = TextAnalyzer.create(alphabet="rus29")
result = analyzer.analyze(text)

# Доступ к улучшенным метрикам
if result.enhanced:
    e = result.enhanced

```

## 📚 Научная база
