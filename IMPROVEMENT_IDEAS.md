# Идеи по улучшению программы анализа энтропии

## 🎯 Краткосрочные улучшения (Easy to Implement)

### 1. Дополнительные статистические метрики

**Что добавить:**
- Медиана энтропии
- Квартили и интерквартильный размах (IQR)
- Коэффициент вариации
- Асимметрия (skewness) и эксцесс (kurtosis)

**Польза:**
- Более полная характеристика распределения
- Лучшее понимание разброса данных
- Выявление асимметрии в стиле автора

**Реализация:**
```bash
--show-extended-stats  # показать расширенную статистику
```

### 2. Квантильная регрессия

**Что добавить:**
- Регрессия не только по среднему, но и по квантилям (25%, 50%, 75%)
- Визуализация доверительных интервалов

**Польза:**
- Учет неоднородности данных
- Более робастный анализ при наличии выбросов

**Реализация:**
```rust
// Построение нескольких линий регрессии для разных квантилей
pub struct QuantileRegression {
    pub q25: RegressionLine,
    pub q50: RegressionLine,
    pub q75: RegressionLine,
}
```

### 3. Автоматическое определение выбросов

**Что добавить:**
- Автоматическое выявление выбросов методом IQR
- Опция `--auto-filter-outliers` для их исключения
- Визуальное выделение выбросов другим цветом

**Польза:**
- Не нужно вручную подбирать пороги фильтрации
- Статистически обоснованное исключение аномалий

**Реализация:**
```bash
--auto-filter-outliers      # автоматически исключить выбросы
--mark-outliers             # выделить выбросы на графике
--outlier-method <METHOD>   # метод: iqr, zscore, isolation_forest
```

### 4. Экспорт в различные форматы

**Что добавить:**
- LaTeX таблицы для научных статей
- HTML отчеты с интерактивными графиками
- Markdown отчеты
- Excel файлы с формулами

**Реализация:**
```bash
--export-latex report.tex
--export-html report.html
--export-markdown report.md
```

### 5. Цветовое кодирование по группам

**Что добавить:**
- Возможность разделить тексты на группы (по жанру, периоду написания и т.д.)
- Каждая группа имеет свой цвет на графике
- Отдельная корреляция для каждой группы

**Реализация:**
```bash
--groups groups.json  # JSON файл с описанием групп
# {
#   "early_period": ["poem1.txt", "poem2.txt"],
#   "late_period": ["poem3.txt", "poem4.txt"]
# }
```

## 📊 Улучшения качества энтропийного анализа

### 15. Нормализация по размеру текста

**Проблема:**
Энтропия зависит от длины текста (эффект насыщения)

**Решение:**
- Использовать нормализованную энтропию: `H_norm = H / log2(N)`
- Или энтропийную скорость: `h = lim(H/N)` при N→∞
- Подгонка модели насыщения: `H(N) = H_max * (1 - exp(-N/N0))`

**Реализация:**
```bash
--normalized-entropy    # использовать нормализованную энтропию
--entropy-rate          # вычислить энтропийную скорость
--fit-saturation        # подогнать модель насыщения
```

### 16. Учет морфологии

**Проблема:**
Русский язык - флективный, начальная буква слова зависит от формы

**Решение:**
- Лемматизация перед анализом
- Энтропия на уровне лемм, а не словоформ
- Учет частотности лемм в языке

**Реализация:**
```bash
--lemmatize                    # лемматизировать перед анализом
--pos-filter <POS>            # анализировать только части речи
--freq-weighted-entropy        # взвесить по частотности в корпусе
```

### 17. Контроль за размером выборки

**Проблема:**
Малые выборки дают ненадежные оценки

**Решение:**
- Bootstrap для оценки доверительных интервалов
- Предупреждения при N < порога
- Коррекция смещения для малых выборок

**Реализация:**
```bash
--bootstrap <N>          # N bootstrap iterations
--confidence-level 0.95  # уровень доверия
--min-sample-size 30     # минимальный размер выборки
```
