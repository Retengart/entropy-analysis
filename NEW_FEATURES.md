# Новые возможности программы

## 🎯 Добавлено в этой версии

### 1. Расширенная фильтрация

Теперь доступны **4 параметра фильтрации** для графиков:

#### Фильтры по энтропии (H)
- `--min-entropy <ЧИСЛО>` - минимальная энтропия (H >= значение)
- `--max-entropy <ЧИСЛО>` - максимальная энтропия (H <= значение)

#### Фильтры по количеству слов (N)
- `--min-n-words <ЧИСЛО>` - минимальное количество слов (N >= значение)
- `--max-n-words <ЧИСЛО>` - максимальное количество слов (N <= значение)

### 2. Подписывание точек с максимальной энтропией

Новый параметр `--label-top-entropy <N>` позволяет автоматически подписать N текстов с наивысшей энтропией на графике.

**Особенности:**
- Точки с максимальной энтропией выделяются **красным цветом**
- На графике отображается **название файла** рядом с точкой
- Удобно для быстрого обнаружения аномальных текстов

## 📖 Примеры использования

### Базовая фильтрация с подписыванием

```bash
# Показать тексты с энтропией от 2.5 до 4.5 и подписать топ-3
cargo run --release -- batch test_poems/ \
    --correlation-plot result.svg \
    --min-entropy 2.5 \
    --max-entropy 4.5 \
    --label-top-entropy 3
```

### Фокус на коротких текстах

```bash
# Показать только тексты с 50-500 словами
cargo run --release -- batch test_poems/ \
    --correlation-plot short_texts.svg \
    --min-n-words 50 \
    --max-n-words 500 \
    --label-top-entropy 5
```

### Комплексная фильтрация

```bash
# Ограничить диапазон по обеим осям
cargo run --release -- batch test_poems/ \
    --correlation \
    --correlation-plot filtered.svg \
    --min-entropy 2.5 \
    --max-entropy 4.2 \
    --min-n-words 50 \
    --max-n-words 8000 \
    --label-top-entropy 3
```

### Multi-poem режим

```bash
# Анализ одного автора с подписыванием
cargo run --release -- multi-poem pushkin.txt \
    --correlation-plot pushkin_labeled.svg \
    --min-entropy 3.0 \
    --label-top-entropy 5
```

```bash
# Сравнение двух авторов
cargo run --release -- multi-poem pushkin.txt \
    --second-file lermontov.txt \
    --correlation-plot comparison.svg \
    --min-entropy 2.5 \
    --max-n-words 1000 \
    --label-top-entropy 3
```

## 🎨 Визуальные улучшения

### Как выглядят подписанные точки

- **Обычные точки**: синие кружки (●)
- **Подписанные точки**: красные кружки большего размера (●) с текстовой меткой
- **Текст метки**: красный, 12pt, показывает имя файла/текста

## 🔧 Технические детали

### Структуры данных

```rust
pub struct FilterParams {
    pub min_entropy: Option<f64>,
    pub max_entropy: Option<f64>,
    pub min_n_words: Option<u64>,
    pub max_n_words: Option<u64>,
}

pub struct PlotParams {
    pub filter: FilterParams,
    pub label_top_entropy: Option<usize>,
}
```

### Алгоритм подписывания

1. Собираются все тексты, прошедшие фильтрацию
2. Тексты сортируются по энтропии (от большей к меньшей)
3. Выбираются N текстов с максимальной энтропией
4. Эти тексты выделяются красным и подписываются на графике

### Обработка имен файлов

Для подписей используется только имя файла (без пути):
- `/path/to/poem.txt` → `poem.txt`
- `C:\Users\file.txt` → `file.txt`

## 💡 Практические советы

### Когда использовать фильтры

1. **`--min-entropy 2.5`** - исключить тексты с очень низкой энтропией (возможно, технические или неполные)

2. **`--max-entropy 4.5`** - исключить аномально высокую энтропию (возможно, ошибки или нехарактерные тексты)

3. **`--min-n-words 50`** - исключить слишком короткие фрагменты, которые могут давать нестабильные результаты

4. **`--max-n-words 1000`** - сфокусироваться на текстах среднего размера, исключив очень длинные

### Когда использовать подписывание

- **Поиск аномалий**: `--label-top-entropy 3` покажет 3 самых необычных текста
- **Валидация данных**: подписывание поможет быстро найти ошибочные файлы
- **Научный анализ**: определение текстов с максимальным разнообразием лексики
- **Сравнительный анализ**: выявление характерных произведений автора

### Оптимальные комбинации

```bash
# Для стихотворений средней длины
--min-n-words 30 --max-n-words 300 --min-entropy 2.5 --label-top-entropy 5

# Для прозы
--min-n-words 500 --max-n-words 10000 --min-entropy 3.0 --label-top-entropy 3

# Для общего анализа с исключением выбросов
--min-entropy 2.0 --max-entropy 4.5 --max-n-words 5000 --label-top-entropy 10
```

## 🚨 Важные замечания

1. **Фильтры применяются только к графикам**
   - CSV и JSON файлы содержат все данные без фильтрации
   
2. **Минимум данных для корреляции**
   - После фильтрации должно остаться минимум 2 точки
   - Иначе будет выведено предупреждение

3. **Подписывание и читаемость**
   - Слишком много подписей (>10) может сделать график нечитаемым
   - Рекомендуется использовать 3-5 подписей для оптимальной читаемости

4. **Комбинирование с другими опциями**
   - Все фильтры и подписывание работают как с `--correlation`, так и с `--correlation-plot`
   - Доступно во всех режимах: `batch`, `multi-poem` (один автор), `multi-poem` (два автора)
