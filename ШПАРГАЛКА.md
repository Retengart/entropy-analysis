## 📖 Основные команды

### CLI

```bash
# Анализ файла
uv run entropy-analysis analyze текст.txt --verbose

# С bootstrap CI
uv run entropy-analysis analyze текст.txt --bootstrap

# Экспорт в JSON
uv run entropy-analysis analyze текст.txt --json result.json

# Пакетный анализ директории
uv run entropy-analysis batch ./texts/ --csv results.csv

# Сравнение двух файлов
uv run entropy-analysis compare файл1.txt файл2.txt

# Справка
uv run entropy-analysis --help
```

### Python API

```python
from entropy_analysis import TextAnalyzer

# Создать анализатор
analyzer = TextAnalyzer.create(alphabet="rus29")

# Анализ текста
result = analyzer.analyze("Мой дядя самых честных правил")
print(f"H = {result.shannon_entropy:.4f} бит")

# С bootstrap
result = analyzer.analyze(text, include_bootstrap=True)
print(f"95% CI: [{result.bootstrap.ci_lower:.4f}, {result.bootstrap.ci_upper:.4f}]")

# Пакетный анализ
texts = [("pushkin", text1), ("lermontov", text2)]
batch = analyzer.analyze_batch(texts)
print(f"Корреляция: {batch.correlation:.4f}")

# Сравнение
comp = analyzer.compare(text1, text2, "Текст1", "Текст2")
print(f"JS Divergence: {comp.js_divergence:.4f}")

# Скользящая энтропия
rolling = analyzer.rolling_entropy(long_text, window_size=50)
```

## 📊 Метрики (15 штук!)

| Метрика | Что показывает | Диапазон |
|---------|----------------|----------|
| **H (Shannon)** | Разнообразие букв | 0 - log₂(29) |
| **x̄ (mean rank)** | Средняя позиция в алфавите | 1 - 29 |
| **σ (std rank)** | Разброс по алфавиту | 0 - ~8 |
| **H_norm** | Нормализованная энтропия | 0 - 1 |
| **H_MM** | Коррекция для малых выборок | ≥ H |
| **Simpson** | P(две буквы совпадают) | 0 - 1 |
| **Gini-Simpson** | P(две буквы различны) | 0 - 1 |
| **Zipf α** | Экспонента закона Ципфа | ~1 для естественных текстов |
| **KL(P\\|\\|Q)** | Различие P от Q | 0 - ∞ |
| **JS** | Симметричное различие | 0 - 1 |
| **Cosine** | Similarity | -1 - 1 |
| **Compression** | Сжимаемость | 0 - 1 |
| **Bootstrap CI** | Доверительный интервал | [lower, upper] |
| **Rolling H** | Динамика по тексту | series |
| **Extended stats** | Q1, Q3, skew, kurtosis | varies |

## 💡 Частые задачи

### Анализ файлов из старого проекта

```bash
# Один файл
uv run entropy-analysis analyze \
    ../entropy-analysis/text/pushkin.txt \
    --verbose

# Вся директория
uv run entropy-analysis batch \
    ../entropy-analysis/text/ \
    --csv results.csv

# Сравнение Пушкина и Лермонтова
uv run entropy-analysis compare \
    ../entropy-analysis/text/pushkin.txt \
    ../entropy-analysis/text/lermontov_new.txt
```

### Создание графиков программно

```python
from entropy_analysis import TextAnalyzer
from entropy_analysis.visualization import create_letter_distribution_chart

# Прочитать файл
text = open("../entropy-analysis/text/pushkin.txt").read()

# Анализ
analyzer = TextAnalyzer.create()
result = analyzer.analyze(text, source_name="Пушкин")

# График
fig = create_letter_distribution_chart(result, sort_by="frequency")
fig.write_html("pushkin_distribution.html")
```

### Batch анализ с экспортом

```python
analyzer = TextAnalyzer.create()
batch = analyzer.analyze_directory("../entropy-analysis/text/")

# Экспорт в CSV
df = analyzer.batch_to_dataframe(batch)
df.write_csv("all_results.csv")

# Корреляция
print(f"Корреляция H vs N: {batch.correlation:.4f}")
print(f"R²: {batch.correlation_r_squared:.4f}")
```

## 🛠️ Troubleshooting

### Проблема: Порт занят

```bash
# Использовать другой порт
uv run entropy-analysis dashboard --port 8502
```

### Проблема: Модули не найдены

```bash
# Переустановить
uv sync --reinstall
```

### Проблема: Docker не собирается

```bash
# Очистить кэш
docker system prune -a
docker build --no-cache -t entropy-analysis:latest .
```

### Проблема: Тесты падают

```bash
# Убедиться что зависимости установлены
make dev
make test
```
