# 📖 Руководство по анализу текстов с разделителями

## Обзор

Новый функционал **Split Analysis** позволяет анализировать несколько текстов, находящихся в одном файле или строке, разделённых специальным маркером (например, `***`). 

Программа автоматически:
1. Разделяет текст по указанному разделителю
2. Анализирует каждый сегмент отдельно
3. Вычисляет энтропию для каждого сегмента
4. Строит **график зависимости энтропии (H) от количества слов (N)**
5. Добавляет **линию линейной регрессии**
6. Рассчитывает **коэффициент корреляции** между H и N

---

## 🚀 Быстрый старт

### Метод 1: Командная строка

```bash
# Анализ файла с разделителями ***
uv run entropy-analysis split-analyze example_split_text.txt

# С пользовательским разделителем
uv run entropy-analysis split-analyze example_split_text.txt --delimiter="---"

# Сохранить график в HTML
uv run entropy-analysis split-analyze example_split_text.txt --html output.html

# Открыть график в браузере
uv run entropy-analysis split-analyze example_split_text.txt --show

# Экспорт в CSV и JSON
uv run entropy-analysis split-analyze example_split_text.txt --csv results.csv --json results.json
```

### Метод 2: Python API

```python
from entropy_analysis import TextAnalyzer
from entropy_analysis.visualization import create_correlation_scatter

# Создать анализатор
analyzer = TextAnalyzer.create(alphabet="rus29")

# Текст с разделителями
text = """
Первый текст для анализа
***
Второй текст более длинный для анализа энтропии
***
Третий текст
"""

# Разделить и проанализировать
batch = analyzer.split_and_analyze(text, delimiter="***")

# Результаты
print(f"Сегментов: {len(batch.results)}")
print(f"Корреляция r: {batch.correlation:.4f}")
print(f"R²: {batch.correlation_r_squared:.4f}")

# Создать график
fig = create_correlation_scatter(batch, show_trendline=True)
fig.write_html("output.html")
```

## 📊 Что анализируется?

Для каждого сегмента вычисляется:

### Базовые метрики
- **N** — количество слов
- **H** — энтропия Шеннона (бит)
- **x̄** — средний ранг буквы
- **σ** — стандартное отклонение ранга
- Количество уникальных букв

### Корреляционный анализ

**Корреляция между H и N:**
- **r** — коэффициент корреляции Пирсона
- **R²** — коэффициент детерминации
- **p-value** — статистическая значимость
- **Уравнение регрессии:** `H = slope × N + intercept`

**Интерпретация коэффициента корреляции:**
- |r| > 0.7 — сильная корреляция
- 0.4 < |r| ≤ 0.7 — умеренная корреляция
- |r| ≤ 0.4 — слабая корреляция

**Интерпретация p-value:**
- p < 0.05 — корреляция статистически значима
- p ≥ 0.05 — корреляция статистически незначима

## 📈 График H vs N

График зависимости энтропии от количества слов включает:

1. **Точки данных** — каждый сегмент текста
2. **Линия линейной регрессии** — показывает тренд
3. **Уравнение регрессии** — в углу графика
4. **Выделение выбросов** (опционально) — точки, выходящие за пределы 1.5×IQR
5. **Подписи точек** (опционально) — для топ-N сегментов по энтропии

### Пример 1: Анализ стихотворений разных авторов

```python
text = """
Мой дядя самых честных правил
***
Белеет парус одинокий
***

"""
```

### Пример 2: Анализ глав книги

```python
# Загрузить файл с главами, разделёнными "---"
with open("book.txt", "r", encoding="utf-8") as f:
    text = f.read()

batch = analyzer.split_and_analyze(text, delimiter="---")

# Показать результаты каждой главы
for i, (name, result) in enumerate(batch.results, 1):
    print(f"Глава {i}: N={result.n_words}, H={result.shannon_entropy:.4f}")
```

### Пример 3: Сравнение стилей

```bash
  --csv, -c PATH          Экспорт в CSV
  --json, -j PATH         Экспорт в JSON
  --show, -s              Открыть график в браузере
```

## 💡 Советы и рекомендации

### Выбор разделителя
- Используйте уникальную строку, которая не встречается в тексте
- Рекомендуем: `***`, `---`, `===`
- Избегайте однобуквенных разделителей

### Размер сегментов
- Минимум ~10-15 слов для надёжной оценки энтропии
- Рекомендуется 20+ слов для точного анализа
- Слишком короткие сегменты могут давать нестабильные результаты

### Интерпретация корреляции
- **Положительная корреляция:** более длинные тексты → выше энтропия
- **Отрицательная корреляция:** более длинные тексты → ниже энтропия
- **Слабая корреляция:** энтропия не зависит от длины текста

### Применение
1. **Атрибуция авторства** — разные авторы могут иметь разные паттерны H vs N
2. **Анализ структуры** — главы книги, части доклада
3. **Сравнение стилей** — научный vs разговорный vs поэтический
4. **Временные изменения** — эволюция стиля автора

## 🐛 Устранение проблем

### Не найдено сегментов
```
Проверьте:
- Правильность разделителя (может быть регистрозависим)
- Наличие разделителя в тексте
- Кодировку файла (UTF-8 или CP1251)
```

### Корреляция незначима (p ≥ 0.05)
```
Это нормально, если:
- Мало сегментов (< 10)
- Тексты очень разнородны
- Нет линейной зависимости между H и N
```

### Выбросы на графике
```
Выбросы — это сегменты, сильно отличающиеся от других.
Причины:
- Очень короткий/длинный текст
- Необычный стиль
- Ошибка в разделении текста
```
